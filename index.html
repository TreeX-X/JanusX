    选择安装包

    日常使用选择安装版；希望直接运行，选择便携版。

  2. 02

    启动 JanusX

    运行下载的 .exe 文件。安装版按向导选择安装位置并完成安装。

    连接你的工作区

    打开本地项目，选择 Shell 开始工作。需要 AI 功能时，再配置模型提供商与 API Key。
