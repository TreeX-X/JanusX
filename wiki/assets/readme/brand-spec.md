# README 首图素材与构图

首图以多终端工作台为主，蓝图作为右下角独立小窗口叠放。`janus-header.svg` 以原有圆角胶囊、软件内同源点阵字标与平滑鼠标移入点击 Star 动画承担品牌识别；不在产品总览里重复 Logo、口号、功能标签或说明文字。说明留在 README，后续语言版本共用图片。

## 构图

- 默认 planche 应用主题；左侧项目与 Worktree、中央 Claude / Codex / OpenCode / Pi 四种终端、右侧文件工具同时展示。CLI 保留各自真实界面与图标，不用 Shell 窗口替代。
- 1920×1080 画布中，主窗口距左 80px、距顶 48px，宽 1760px；蓝图小窗宽 856px，距右 32px、距底 28px。小窗覆盖右下终端的下半部分，侧栏项目树和文件树仍可见。
- 蓝图采用完整工作台截图，展示 Note、模块关系与维护对话；这是两个真实操作时刻的素材合成，不表示产品内新增蓝图浮窗模式。蓝图章节另用完整工作台图，支持点击放大。
- 共用背景采用原创 macOS 壁纸感的流动曲面，兼容经典黑与默认石板色：雾银灰 `#95A6A5` / `#CBD0C5` 为底，烟青 `#6C8286` / `#3D5960` 形成下方折面，少量香槟灰 `#CDC5AF` 从右上延伸。配色保持低饱和与中等明度，避免背景过暗吞没黑色窗口，也避免大面积暖黄与石板色融在一起。宽缓曲线和柔和高光保持安静，不使用 Apple 壁纸素材。窗口采用半透明白色细边和中性烟青软阴影；蓝图浮窗取消纸灰外框。
- 背景源 `showcase-background.svg` 与导出 `showcase-background.png` 固定为 1920×1080，首图和后续 GIF、静态图共用同一张不透明 PNG；不随应用主题换底，不叠加动态纹理、网格、角标或文字。
- 参考 https://github.com/stablyai/orca 的产品优先与低文案密度；不使用其图片、品牌或移动端能力。

## 导出与后续替换

`scripts/showcase/showcase-config.mjs` 的 `style.background.asset` 指向同一张底板，公共合成器已接入，并使用细边与软阴影。两帧明暗诊断 GIF 经浏览器解码，跨多次循环的 8 次采样中，应用区确实切换、区外像素完全不变。该检查验证固定底板的合成稳定性，不表示其余功能 GIF 已重录或重编码。

后续重录更新原始 PNG 后再执行导出。保留完整侧栏、可读节点、真实输出；不把说明烧进图片。录制中使用演示仓库与本地模型，不能带入真实账号、私有路径、个人对话或密钥。其余 GIF 的时间线、鼠标衔接与编码仍按 README 演示计划实施。
