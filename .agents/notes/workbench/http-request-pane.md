# HTTP 请求 pane

## Intent

用户要一个内置的 HTTP 请求工具，用来调试自己项目里的服务。它是中央工作区的一种新 pane 内容类型，与 [Docker 面板](./docker-management-entry.md) 配套：一边发请求，一边在旁边看容器日志。本文只记录方向与入口，尚未实现。

## Agreed direction

HTTP 请求是新的 pane 内容类型，不是浏览器里的一个网页，也不放进右侧窄面板。用户眼里它应该和终端、编辑器、浏览器一样，是一种能打开、拖动、并排显示的工作区标签页：复用 Janus 现有的标签页与分屏，整个面板可拖到上下左右边缘创建分屏、拖到中央合并为标签、用工作区分隔线调比例。与 Markdown 独立 pane 走同一条改造路径（见 [Markdown 独立 pane 与顶栏工具分组](./markdown-pane-entry.md)）。

它买的是 JanusX 的分屏，不是一个更强的 Postman：

```text
当前项目 / 当前 worktree

┌─────────────────────┬─────────────────────┐
│ HTTP 请求            │ API 容器日志         │
│ POST localhost:8080 │                     │
│ /api/users          │ 请求到达、处理结果    │
│                     │                      │
│ 请求参数 / JSON      ├─────────────────────┤
│                     │ 代码编辑器           │
│ 响应：201 · 42ms     │                     │
└─────────────────────┴─────────────────────┘
```

发送一次请求，旁边立即看到服务日志——这正是终端 + 分屏已有的工作方式，请求页只是补上了"发出请求"这一格。日志来自 Docker 面板，编辑器是既有仓库文件编辑器，请求页只需要把自己那一格做好。

入口保持简单，三个就够了：

- **新建标签页 → HTTP 请求**：随时创建一个临时请求。
- **Docker 服务 → 调试接口**：把服务可访问的地址带入新请求页；具体路径由用户填写。
- **项目内保存的请求 → 点击打开**：重新打开常用接口。

请求页至少承载方法、URL、请求头与请求体（JSON）、响应状态与耗时、响应体。保存的请求按项目/当前 worktree 归属，跟随工作区切换恢复，这点与 Markdown 草稿的作用域问题同源（见 markdown-pane-entry.md 的 Draft ownership and lifetime）。

## Rationale and validation

调试本地服务时的动作是连续的：改代码 → 重启容器 → 发请求 → 看日志 → 再看代码。把这五格摊在同一屏上，比在 Postman、Docker Desktop、编辑器三个窗口之间来回切更快，也不需要把服务地址和接口定义搬到 JanusX 之外。临时请求不需要保存，常用接口才需要——所以入口只给"新建"和"打开已保存"两个动作，不做请求集、环境变量、脚本断言那套完整 API 客户端能力。

内置浏览器已经能打开 HTTP 地址，但它是"看页面"的工具：发 POST、带 JSON 体、看状态码和耗时都不是浏览器地址栏能做的，也无法并排嵌进工作区分屏。

尚未验证：跨域与自签证书下的请求行为、大响应体的呈现、请求历史与保存请求的持久化边界。实现前需要一个本机可用的服务实测。

## Decisions

2026-10-14 定为新的 pane 内容类型（不停留在浏览器网页或右侧面板），入口只做三个，保存的请求按项目/worktree 归属。

## Open questions

- 保存的请求存哪里：项目内文件（可进 Git、可手改）还是应用数据目录。倾向项目内文件，实现时定。
- 响应体的呈现形式：纯文本/JSON 美化，还是也要预览 HTML 与图片。首版倾向前者，HTML 预览交给内置浏览器。
- 与 Docker 面板的联动深度：只把地址带进新请求页，还是也提供"对这个容器发请求"的快捷入口。首版只做前者。
- 顶栏是否常驻 HTTP 请求入口，以及与 Docker 面板入口的分组方式。

## Implementation

尚无 Task。依赖 [Docker 面板](./docker-management-entry.md) 的 pane 内容类型改造先落地，请求页复用同一套内容类型与拖拽落点。
