# Chat 联动备忘录与线性里程碑

## Intent

探索 Chat 联动的可编辑备忘录：对话后由 Janus 自动整理，用户也能直接编辑；通过右侧悬浮备忘录持续查看和维护，并支持工作区映射。备忘录以文件为单位，可多份，每份含一条线性里程碑。当前只维护产品想法，未实施，不是需求或实施契约。

## 产品方向

用户提出参考飞书式体验，对话后自动整理内容，同时允许人工直接编辑。Chat 中可打开右侧悬浮备忘录，也希望支持主动打开；Janus 通过扩展工具读取与编辑同一份记录。

备忘录承载背景、想法和讨论结论，节点内以自然语言描述对应的事情与要点（含具体行动的表述），里程碑用线性节点组织这些内容。记录需要持续保存和维护；会话内的 `todo_write` 仍只用于当前回合的执行步骤，不能作为持久备忘录的替代。

## 备忘录状态（已明确）

janus-chat 提供备忘录状态开关。未开启时只能对话；开启后可结合项目上下文读写与编辑备忘录，chat 原有能力不受影响。该开关是备忘录读写与自动整理的总门：整理触发的细节仍待细化，但备忘录读写只发生在开启状态。

维护范围以打开的备忘录文件为准：打开哪份就维护哪份。janus-chat 的读写、整理和"未归入节点"归入都作用于当前打开的文件，归入目标在本文件的线上选择节点，不做跨文件归入；切换文件即切换维护上下文。

自动整理默认由自然语言触发：对话中出现值得记录的表述或明确要求整理时即整理，不设定时器、批量任务或额外手动整理入口。

## 存储与工作区映射（已明确）

备忘录文件存于 Janus 应用内，不随项目仓库复制；工作区通过映射关联。默认映射 chat 会话引入的工作区，可通过自然语言继续补充映射。原先"记录归属 vs 内容涉及工作区"的区分收敛为这一组映射：跨项目计划保持一份备忘录文件、映射多个工作区。切换工作区后的可见与筛选规则仍待细化。

## 线性里程碑（已明确）

一份备忘录文件对应一条里程碑线：备忘录文件可多份，每份内是一条线；线是多个有顺序的节点，节点内含多个"点"作为记录维护单元。点以自然语言描述对应的事情与要点，由 janus-chat 编辑。

节点可以用版本或时间表达相关标注，但线性顺序独立维护，不按版本号或时间自动排序。修改节点标注不改变位置，不要求日期递增或版本连续，也不根据这些标注计算节点间距离。节点的先后表达组织顺序，不额外推导必须依次完成的限制。

节点不维护完成状态等任何状态字段；后续由用户在对话中描述是否调整或删除节点，由 janus-chat 执行。因此折叠态不再以待办完成数量作为状态呈现，收敛为节点标题与版本或时间标注；展开态显示完整内容，就地阅读和编辑，不另跳到独立详情页。（本条修订此前"折叠态含待办完成数量"的呈现方向。）

备忘录文件之间的切换与管理入口预计设计在 chat 左侧子 island 的左侧区域，以备忘录列表 tab 呈现：支持新增、删除、选中以及 tab 折叠。

保留"未归入节点"区域接住零散的点，之后由用户或 Janus 归入本文件内的对应节点，不要求每次随手记录都先创建里程碑。该区域方向已获用户认可；归入时如何选择目标节点的判断规则仍待细化。

例如可以依次排列"v0.9：编辑基础""10 月 20 日：试用反馈""v1.0：首版整理"。中间节点从日期改为版本标注、或者日期调整到其他节点之前，均保持原有位置。示例只说明顺序与标注独立，不确定实际排期。

## 交互与整理建议（待讨论）

建议用户和 Janus 共用同一份持久记录及编辑入口。人工编辑自动保存，工具尽量局部更新节点内容；写入前核对版本，避免迟到的整理结果覆盖人工修改。节点身份应独立于标题、版本、时间和位置，改名或调整顺序后仍能关联原内容和对话来源。

建议对话整理区分想法、明确结论与行动要点，模型提出的建议保留建议身份。自动整理不因提到新日期或版本就重排节点；工具调整顺序应对应用户表达的排序意图。零散内容可以先进入"未归入节点"区域；自动选择目标节点的规则、新节点如何插入仍待确定。

普通对话整理后建议先轻提示，已展开时直接同步，不每轮重复展开或抢走编辑焦点；这以备忘录状态开启为前提。默认提示规则尚未确认。

## Open questions

- 节点呈现：是否允许同时展开多个节点；折叠态的具体尺寸和长标题处理。
- 顺序维护：人工调整的交互方式、工具调整顺序的条件，以及自动整理的新节点插入位置。
- 自动整理：目标节点选择、来源关联及人工修改冲突的处理（触发已定为自然语言）。
- 未归入归入：从"未归入节点"归入本文件节点时选择哪个节点的规则与交互。
- 工作区映射：切换工作区后的可见范围与筛选呈现；映射是否需要落到节点级。
- 主动性与提醒：整理提示的默认规则、结合记忆给建议的深度、定时或条件提醒的范围及提示渠道。
- 排期：是否并入后续个人画像/记忆建设阶段（见[个人画像与记忆工作台](personal-memory-workspace.md)），还是独立评估。
