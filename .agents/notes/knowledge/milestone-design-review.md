# 里程碑设计评审：问题与改进方向

## Intent

围绕[Chat 联动备忘录与线性里程碑](user-todo-janus.md)盘点设计、实现与验证问题。本篇维护探索性判断及改进取舍，不替代用户已确认的专题边界。评审最初由左侧面板被截断触发；第一版工程实施、验证命令和限制由专题维护。用户已授权本轮实施，固定外岛、共享附岛动效、真正的星座、原子删星、逐条记录与滚轮／中键相机已完成；本篇维护取舍、实施结果及仍待验证的边界。

## 保留的产品取舍

### 有序大纲与里程碑名称

节点无完成状态，版本／日期为自由文本，数组顺序不推导依赖或完成约束。因此当前能力是带来源的有序记录，不能承诺进度、日期排期或依赖执行。名称是否进一步收敛仍可评估；此次不因名称争议增加用户未要求的完成字段。星座选中只表达阅读位置。

### 会话一一绑定

切换文件或主动退出会开新会话，这会增加临时浏览另一份记录的操作成本。但旧会话没有被销毁：它仍在列表中，流式回复在原会话后台完成，可随时返回查看和继续。触发器、Escape、视图切换和自动适配只隐藏展示，不退出；同文件切节点不切会话。当前行为已获确认，优化保留它。若以后改为独立浏览，需要重新设计浏览文件与维护目标的表达，不能只改事件处理。

### 节点归属与后续生态

早期未归入承接零散想法；用户已明确要求移除该入口及其中全部记录。当前 v3 只保留星内记录，旧 v1／v2 首次读取时原子升级并删除未归入数据，修订增加一次，保留已有星内身份和来源。空备忘录先建星；模型目标或分组不明确时先询问，不再写入 null 节点。生态扩展另行设计。memo 管持久背景、想法和结论，todo_write 管当前轮次步骤，模型提示已明确两者用途。

## 已处理的结构问题

| 历史问题 | 当前结果 |
|---|---|
| 左侧浮层截断、margin 反馈、正文挤窄 | 采用联合视口几何、顶层浮层和四种自适应工作面；窗口缩小时立即满足边界 |
| 面板直接挂载卸载、文件栏与遮罩无过渡 | 进入／退出生命周期保留 DOM 和占位、协调主岛让位和复位，快速反向操作取消旧清理 |
| 所有节点正文同时堆叠 | 底部星座选择节点，上方只显示选中内容；星点、星旁引线、稳定 ID、键盘及相机已实现；文字和引线以同一星按钮定位 |
| 切换反馈缺少星座渐进显现 | 可见节点错峰、连线展开，最长约 324ms；快速文件切换取消旧动画，减少动效可关闭 |
| 文件持久映射与 Chat 资源耦合 | v3 不含工作区或未归入字段；v1／v2 完整校验后在首次读取时原子升级，保留星内内容和来源 |
| 壳侧独立模型阶段与截断上下文 | janus-agentX 增加宿主本地工具端口；memo_read/edit 并入正常 Chat 轮次，移除独立模型阶段 |
| 旧固定文件指引、canAccess／setChatAccess 用例残留 | 提示词改为会话绑定；测试与当前接口一致，真实桌面持久化用例已重新通过 |
| 文档与下游入口漂移 | 专题改为当前设计、边界及验证；知识模块入口、wiki 模块映射和相邻仓库说明同步 |

历史独立阶段曾额外发起模型调用、限定五步和最近八条消息，并把阶段结果传给普通回复。这是当时无工作区宿主工具入口缺失的成本，不能再描述为当前实现。整合后的真实模型判断质量和成本仍需独立试跑，工程替身验证不替代它。

## 布局与动效验证

第一版联合布局的正文容器在 1280px 为 276px，在 1000×600 为 250px；它解决了旧版约 89px 正文和主体覆盖问题。第一版节点导航位于文件栏、正文共同下方，使用全画布宽度，完整高度 80px、上下排列压缩为 64px；代价是占用一段正文高度。

第一版浏览器组合首次 14 通过、2 失败：自动文件栏宽度过渡曾短暂挤窄正文，静态间距断言也读到了入场动画中间位置。自动适配改为立即满足边界，静态测量等待动画完成后，最终 21 项浏览器用例通过。真实桌面持久化／重启恢复和完整 Titlebar 的最小窗口／125% 缩放两项通过。深色与 planche 截图已检查，路径和完整命令见专题。

此前主体 island 的四项旧断言失败来自空 Knowledge 提示、隐藏工作区入口、旧会话下拉及已取消的展开拖动；改动前对照也以相同断言失败。该版没有改写这些产品行为，未声称整套主体回归通过。

动画使用最终几何作展示过渡，不用运动中的主体矩形反算附岛。旧文件动画回调不写选择或正文；暂时隐藏保留编辑器，跨节点、文件和开合的冲突草稿按身份恢复。合成 IME Enter 事件已验证不触发保存，但真实中文输入法组合、系统 DPI、多显示器仍未专门验收。独立窗口及其它 body 浮层继续后置；本轮圆桌附岛已迁移共享几何，窄窗两岛边界和关闭恢复通过浏览器检查。

## 本轮交互改进结果

### 固定外岛和岛内文件列表

layoutMemoIslands 已委托共同布局求解器，filesCollapsed 只决定内部 compactFiles，不参与两岛外框判定。在完整并排下，手动折叠将文件栏变为窄轨，正文使用释放空间；展开恢复内栏。窗口导致的紧凑、上下排列与单工作面独立处理，窄窗仍可打开岛内文件抽屉，自动适配不写回手动偏好。

浏览器实测折叠前后 memo 和主岛外框完全相同，正文变宽；最小窗口、模式恢复、草稿及光标保持仍通过原有回归。星座使用全岛宽度，不随文件栏压缩。

### 共享附岛开合与最终几何

此前 memo 和圆桌分别维护清理定时、不同开合时长与固定偏移，圆桌关闭回调可能清理刚重新打开的模块。本轮提取 islandMotion.ts／css：useIslandPresence 管理四阶段并取消过期回调，useIslandReveal 只编排可见内容，createIslandGeometryMotion 展示最终几何；基础开合统一为 220ms。memo、羊皮纸、角色结果与问题池已迁移，共用 layoutCompanionIslands 的左右布局和四种工作面。

圆桌 useAuxiliaryIslandLayout 保存并恢复自己拥有的样式和 inert，resize 立即满足边界；JanusAuxiliaryIsland portal 到 body，保留自己的材质和正文。关闭后恢复焦点，快速重开保留原开启入口。原 auxiliaryClosing、独立展示清理计时、入退场 keyframes 和运行球 CSS 中的旧强制偏移已删除。显式“新主题”的业务重置仍由原业务流程负责，不把动画完成当成会议重置。

共同机制只负责展示、几何和取消，不承接 Chat 会话、实际数据读取或模块注册。此抽取以两个宿主的实际共性为界，未扩大成插件体系。减少动效直接稳定呈现。羊皮纸快速关开及窄窗两岛边界、间距和关闭恢复已动态验证；角色结果与问题池的接线已迁移，完整业务流程未单独做端到端验收。

### 星座表达与文字对齐

MemoConstellation 以星按钮、细 SVG 连接、引线标题和可选标注表达有序节点。constellationLayout 按 UUID 生成不等距、有方向变化的布局；插入只调整直接邻居，删除保留其余坐标，排序重用原有位置。标题修改和选择不重排。视觉坐标与业务顺序分离，不增加分组、分支或完成语义。

星、局部引线与文字共用中心锚点；标题在引线上方 4px、标注在下方 4px，朝左时左端对齐，朝右时右端对齐。标签从四个方向中按视口、星点、已放置标签和连接择位，文字维持 11px／10px 屏幕字号。轻弧共用绘制、逻辑插入及裁切几何，连接避开文字和引线。四向择位是局部启发式，不保证高密度时所有文字互不重叠。

### 插入、选择、删除与逐条记录

| 场景 | 已实施行为 |
|---|---|
| 空白点击 | 临时星、连接预览及就地输入；回车确认、Esc 取消，空标题不写入，再点空白保留标题并换目标 |
| 相邻星之间 | 未裁切逻辑连接附近 34 CSS px 内优先插入；首星外侧明确区域插最前，其余空白追加 |
| 冲突 | 捕获文件、修订和前后锚点；失败保留输入，刷新后显式重试；锚点改变要求重选 |
| 选择与删除 | 稳定 ID 与业务顺序键盘导航；确认后一次原子删除星及全部记录，清理对应草稿 |
| 上方编辑 | 隐藏重复文件名、保留数量，标题／版本分层；编号记录行、保存状态反馈、行菜单承载移动／排序／删除 |
| 添加记录 | 右上角按钮打开正文内多行输入，Ctrl／Cmd+Enter 提交、Esc 取消；跨节点切换恢复草稿 |

星、文字和引线点击选择，中键拖动不创建。工具栏与星菜单保留显式添加入口。持久结构不增加相机或未归入节点，沿用 addNode.afterId 和 removeNode，保留已有永久删除语义。

### 滚轮缩放与中键拖动

滚轮仅在星座视口控制缩放，以指针位置为锚点，范围 0.4–2.4；中键指针捕获控制二维平移，并屏蔽误选和误插入。屏幕坐标统一由相机投影得到，插入绑定业务 ID。相机有界，不改变外岛尺寸或节点顺序；上方记录滚轮仍正常滚动。

缩放按钮和回到选中星按钮提供无需中键的入口；键盘 +／-／0 等价，聚焦画布后的方向键平移。选星仅作必要的可见性调整，同文件正文编辑不重置手动相机，切文件重新建立相机。普通模式星座占 180px，上下排列压缩为 112px，均经窗口回归；适应全图未作为本轮必需交互增加。

## 空白创建、自然星座和文档式编辑（已实施）

用户采纳空白创建、自动接入、相邻插入和自然走线，并要求改善上方编辑区。本轮采用“疏密星群与局部轻弧”：自然感来自节点距离、方向和留白，浅曲线只作辅助。固定六星折返和透明悬停加号已移除。连续大弧容易呈现轨道感且不适合扁视口，因此未采用。

MemoPanel 按文件缓存坐标，切文件与隐藏／重开仍保留；宿主卸载或应用重启后按 ID 和当前顺序重建，不持久保存。插入取相邻位置并作法向偏移，直接邻居最多让位 18px，远星保持坐标；追加在横向边界转向并扩展纵向世界。完整重启后插入形成的局部形状可能不同，这是不扩展存储结构的代价。

临时星保存点击世界坐标，只有保存成功才播放 380ms 短弧移动。useConstellationMotion 用单个可取消帧循环更新星和连接，完成后显示新星标注，必要时相机跟随；减少动效直接到位。失败不播放成功动画；关闭／切文件使过期展示失效，已成功持久化的数据仍按真实结果呈现。提交禁止重复执行，移动期间短暂不接受空白点击。

MemoEditor 提供文档式标题、可清空的版本／日期、编号文本行及保存反馈。单行回车、多行 Ctrl／Cmd+Enter 和失焦保存；Esc 撤销当前修改，输入法组合回车不提交。新增记录在正文内输入，替代中心弹窗。移动、排序和删除收进行菜单，点击外部收起，避免遮住星菜单；保存失败与冲突保留草稿供重试。

四向标签缓解交叠，连接裁切仍会留下空隙，高密度时连续感及文字碰撞不能视为完全解决。星座保持 180px／上下布局 112px，继续用相机浏览。可拖动分隔条、持久布局、持续输入防抖和重启草稿恢复后续评估，不引入图形引擎或新业务节点类型。

新增验证覆盖局部让位、远星稳定、反复插入／重排、跨缩放逻辑命中、四向标签裁切、单星逐帧运动、取消／失败／锚点失效、迟到保存、菜单互斥与行内草稿。实际命令和最终结果由备忘录专题当前验证节维护。

### 浅色背景层次

备忘录沿用主体浅色主题的米黄底色，由共享主题变量派生层次：外壳使用 shell-pane；文件栏与星座区混入 25% shell-pane-chrome，正文只混入 6% 白色。文字、强调色和弱边线沿用主体变量，使两个 island 保持同一色相，减少原全画布叠加 38% 白色的亮度差。独立暖灰方案因与主体色差过大被用户否定，当前不再使用固定暖灰色值。菜单与输入浮层沿用外壳色，深色主题及几何布局不变。现有双主题截图检查通过，最终浅色截图已查看。

本轮单元、浏览器、桌面、构建及翻译检查以专题当前验证节为准，历史通过数不作为新交互证据。完整命令、截图及历史失败后修正由[备忘录专题](user-todo-janus.md)维护。初次新交互组合有一项因漂浮按钮的自动稳定等待失败，修正点击方式后通过；圆桌旧 CSS 位移由自检发现并补充边界断言。

## 其余后续优先级

1. 用真实模型凭据验收目标节点选择、去重、多轮整理、用户决定与模型建议区分，以及共享轮次的延迟与成本。
