# 记忆与知识

## Goal

组织个人记忆与工程知识的处理队列、检索、审核与召回。当前入口包括 KnowledgeProcessingQueue、KnowledgeAutomationService 和 KnowledgeSearchService。自动处理服务维护提取、条目审核、主题 Wiki 生成和复核任务；审核服务维护人工及自动提交，发布恢复日志与历史服务共同保存 Wiki 版本。具体模型选择和未完成质量验收由各需求、决策及任务说明。

## Scope

终端 Hook 通过 CaptureInbox 持久化待写证据，TranscriptRecovery 在读取有限原始会话前保存补读任务，由 AgentTurnRecorder 恢复调度；自动处理按任务上下文提取，提纯与独立覆盖检查通过后才提交审核。`knowledge:diagnostics` 的 captureRecovery 字段提供待恢复批次、事件和错误，transcriptRecovery 提供待补读数量及最近错误；[Hook 证据与提纯决策](./2026-10-05-hook-evidence-extraction--a61e849c.md)说明来源身份、检查点、审核上下文及语义去重限制。

工程知识与个人画像分别控制采集、处理、召回和界面入口，共用“知识与记忆”工作台。`settings:personal-memory:get/update` 独立读写个人设置，不覆盖工程模型配置。[分域控制决策](./2026-10-04-memory-domain-controls--908d675a.md)说明装配门禁、审核筛选及个人保留期语义。

本模块声明稳定的职责和入口，不将计划中的模型部署描述成当前实现。工程 Note 原文读取与蓝图属于 Note 与蓝图模块；知识内容的生成、检索与审核在本模块内维护。

右侧助手承载工程检索、画像与统一审核，个人完整工作台维护卡片分类、搜索和详情；[助手布局决策](./2026-10-04-assistant-persona-layout--6e9c114d.md)说明入口兼容与双尺寸呈现。外部知识 MCP 由独立进程读取持久配置约束；knowledge:external-mcp:probe 验证宿主生成的启动配置，客户端适配与未验证范围见[终端覆盖决策](./2026-10-04-mcp-terminal-coverage--b74b3c92.md)。

`knowledge:automation:status` 返回配置环节模式和当前有效队列投影，携带版本标识、独立工程审核开关及候选 hash/工作区/任务身份，并提供当前计划的可选脱敏标题和真实最近成功时间。助手各子页、工作台与角标共享状态读取，历史任务和计数仅包含工程域并独立保留；重试复核当前计划和依赖。投影不触发处理或授予发布权限，个人记忆不进入工程自动审核。新 automation 配置拒绝旧评分/精炼请求，派生候选入口拒绝独立图关系提议；历史仍可读取和维护。Wiki 页间关系保存在页面及草稿的 relations 中，目标身份/版本与来源在同一发布锁内复核，历史保存同版本正文和关系；relationIssues 只反映当前目标状态，不写回审核依据。主题分组复用已发布身份及显式概念。默认图谱只投影已发布 Wiki 与宿主核验过的页间关系；单页来源追溯按工作区隔离事实、实体与旧边，原始证据通过既有只读上下文接口按需加载，不受最近来源列表限制。当前约束及边界见[审核实施任务](./2026-10-06-knowledge-review-status-audit-plan--76ef32d1.md)。

`knowledge:automation:run` 接收可选 taskId，仅执行指定任务；reevaluate 明确重跑当前评分未达标项，普通设置保存不触发该动作。`knowledge:automation:retry` 接收任务 ID 或候选 ID、工作区与候选 hash，后者仅准入所选历史版本。状态与任务保留真实 Jev 评分、当时阈值及最多 20 次此前尝试，界面按失败原因提供重试、恢复或人工审核。OpenCode 完成事件通过既有会话数据库读取器补齐正文，恢复以会话、工作区和结束时间绑定原回合。阈值、恢复及记录阅读的约束见[审核实施任务](./2026-10-06-knowledge-review-status-audit-plan--76ef32d1.md)。
`knowledge:automation:status` 为当前队列与最近任务追加可选 subjectState，只读关联候选类型、工作区、ID 及当前状态，或明确无候选/不可用/多产物提取。持久化执行结果和历史计数保持原意；候选现状不覆盖历史失败，也不伪造最近成功时间。工程审核关闭时不读取关联快照，旧宿主缺少该字段时界面不推断可审核对象。

`knowledge:audit:page` 按领域、工程及操作过滤，在同一日志快照内返回分页事件与计数；游标绑定过滤条件和日志前缀，追加事件在刷新后可见。旧列表接口保留数组返回，统计兼容过滤参数。个人事件以 workspaceId=user 识别，工程页排除个人及无明确工程归属的系统事件；全域历史仍可读取。审计列表保留完整事件用于只读前后变更，当前对象通过已有查询独立读取；具体边界见[审核实施任务](./2026-10-06-knowledge-review-status-audit-plan--76ef32d1.md)。

`knowledge:configuration:test` 接收单环节模型配置和可选 Jev 临时凭据，使用固定样本返回配置缺项或可用性结果。宿主检查工程知识功能门禁，本地测试只复用已检测启用的配置；测试不读取用户资料、不保存设置、不提交候选或 Wiki。设置页按四环节串行调用；超时、密钥与失效边界由[工程自动处理需求](./2026-10-03-knowledge-accumulate-review-wiki-rereview--3944b368.md)约束。

本地模型启停由本模块宿主负责：`knowledge:local-model:configure` 经环境检测授权本地选择，`knowledge:local-model:stop` 持久关闭并释放托管进程。普通设置保存不得反向启用；环境检测、上下文预算与进程生命周期分别维护，外部管理服务的进程不归应用所有。

本模块维护本地模型资源准备：`knowledge:local-model:install` 在显式操作后下载固定版本、校验并缓存程序与权重，`knowledge:local-model:resources-status` 提供进度。资源不进入发布包，启用与冷启动由 GPU 环境预算约束；取消、创新开关关闭和应用退出中断准备工作，已校验资源留在 userData 中供升级复用。

[记忆与知识演进专题](./2026-09-26-memory-knowledge--c0a75c6a.md)承载模型选择、个人记忆与工程知识隔离的阶段计划；专题 parent 指向本模块，其历史决策链和验收语义各自保留。

[个人与工程知识分离决策](./2026-09-18-personal-engineering-separation--296ddf52.md)记录隔离依据；[统一记忆内核需求](./2026-09-28-unified-memory-laya-primary--736081fc.md)仍是待交付的改造方向，关联它不表示真实数据质量已经验收。[工程自动处理与 Wiki 手册](./2026-10-03-knowledge-accumulate-review-wiki-rereview--3944b368.md)约束当前自动提交、提供方配置及发布历史；历史不参与默认 BM25 与 MCP 召回。

Jev 凭证由本模块加密保存。`knowledge:jev:credential-status` 只返回是否已配置；设置页的显式显示操作调用 `knowledge:jev:credential-reveal`，宿主检查 knowledge 开关后返回已解密凭证。普通配置和状态投影不携带明文，显隐和保存反馈由[工程自动处理需求](./2026-10-03-knowledge-accumulate-review-wiki-rereview--3944b368.md)约束。
