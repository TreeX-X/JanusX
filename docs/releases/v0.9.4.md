# JanusX v0.9.4

相较 v0.9.3，本版本重点改进文件预览与差异阅读体验，并新增 Android 局域网远程终端测试能力。桌面发布包仅开放局域网测试，跨网功能继续在开发构建中保留。

## 新增功能

### Android 局域网远程终端（实验性）

- 电脑生成配对二维码，Android 扫码后由电脑确认授权，无需 JanusX 账号或组织。
- 手机可在授权工作区新建电脑端真实 Claude Code 终端，查看持续输出并发送输入；CLI 安装、登录与运行仍在电脑端完成。
- 手机使用离线终端屏幕显示 ANSI 颜色、光标与中文内容，提供适宽、字号调整、历史滚动和同步操作。
- 支持同一终端的断线重连与输出回放；关闭远程服务或手机断开后，电脑端终端继续运行。
- 提供独立 Android 测试安装包 `JanusX-Android-0.1.13-lan.apk`，可与已有开发测试 App 共存。

### 文件窗口与预览

- 统一内嵌预览与独立文件窗口的标签、窗口控件和工具栏交互。
- 完善右侧工具区、文件编辑与 Office 预览控件的一致性。
- 增加文件变更行数摘要，便于查看新增与删除规模。

## 体验改进

- 优化 Diff 行号显示，减少左侧重复数字；调整差异底色、文字权重和留白，提高连续阅读清晰度。
- 简化编辑器辅助线与差异装饰，减少无关诊断和视觉干扰。
- 改进工具与终端标签切换、文件预览打开过程及标签关闭按钮的反馈。
- 调整右侧工具栏展开、悬停与滚动交互，并完善触控板横向滚动行为。
- 简化手机配对面板，连接设置按需展开，连接阶段、待批准设备与终端状态更清楚。
- 配对二维码显示有效期倒计时并自动更新；更新二维码保留已授权连接与运行中的终端。

## 问题修复

- 修复较老 Android WebView 无法解析终端脚本导致的空白屏；用户已在真机确认该问题修复。
- 补充终端页面加载、脚本异常和启动超时反馈，支持重建显示页并回放原终端输出。
- 修复快速重连时旧信令连接尚未释放造成的入房冲突，并隔离旧连接回调。
- 修复文件窗口标签滚动条、编辑区域布局保留及关闭按钮悬停等显示问题。
- 修复非 Git 仓库路径的状态查询，返回明确的结构化结果。
- 整理合并工程文档，修复发布检查发现的失效引用，并同步打包依赖排除清单。

## 安装与升级

| 平台 / 文件 | 用途 |
| --- | --- |
| `JanusX-0.9.4-x64-setup.exe` | Windows x64 安装版 |
| `JanusX-0.9.4-x64-portable.exe` | Windows x64 便携版 |
| `JanusX-Android-0.1.13-lan.apk` | Android 8.0 及以上的局域网测试版 |

桌面用户可通过应用更新功能升级，或下载安装包。便携版用户请保留原有数据目录，并按原使用方式更新程序。

Android 测试版名称为 **JanusX LAN Test**，包名为 `com.janusx.p2plab.lan`，使用测试签名。它与原开发测试版的数据独立，安装后需重新扫码授权。

使用手机远程功能时，手机和电脑应连接同一局域网。在电脑的「设置 → 创新功能」中开启远程协作控制，再从底部手机入口生成二维码；若使用开发构建，请先选择局域网连接。

## 已知限制

- 手机远程为实验功能，默认关闭。v0.9.4 发布包不提供公网信令或 STUN 配置，Android LAN 测试版拒绝跨网配对信息。
- 当前手机远程新建终端面向 Claude Code；其他 CLI 的手机控制能力不在本次交付范围内。
- 手机 App 离开前台会断开连接，返回后可手动重连；关闭电脑远程服务后的状态更新可能等待 UDP 断开检测。
- 手机端长期使用尚未测试；不同机型的显示、软键盘、旋转与网络切换体验仍需继续验证。
- 手机端显示和界面设计优化、长期使用测试及进一步跨网开发计划在 v0.9.5 继续推进。
